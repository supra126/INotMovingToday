# 工作區改版（Runway 式介面）設計

日期：2026-10-13
狀態：待審

## 目標

把 INotMovingToday 的兩個模式（單鏡生成、分鏡模式）改成像國際大廠工具的專業工作區：版面與操作參考 Runway，視覺沿用 IGiveUpOnLife 的設計系統，讓兩個工具看起來是同一家的產品。

**只改外觀與版面，不改功能。** 現有的流程、資料、AI 呼叫、關卡與花費確認全部保留；所有單元測試照常通過。

## 決定

- 分鏡模式用「鏡頭欄＋大畫面＋設定面板」（方案 A），③ 分鏡圖另有「總覽」切換（方案 C 的格狀比較）。
- 只做深色主題。
- 桌面優先；手機寬度只需可閱讀、不需好操作。

## 設計系統（從 IGiveUpOnLife 複製，不跨 repo 引用）

- **顏色**：IGiveUpOnLife `app/globals.css` 的深色數值，直接放進 `:root`（不做 `data-theme` 切換）：
  `--canvas` 0.17、`--panel` 0.205、`--raised` 0.24、`--sunken` 0.15、`--line` 0.29、`--line-strong` 0.37、`--fg` 0.94、`--fg-muted` 0.72、`--fg-subtle` 0.66、`--accent` 0.95（近白）、`--accent-fg` 0.17、`--accent-soft`、`--danger`、`--success`、`--warning`（皆為 oklch，色相 260，數值照原檔）。
  Tailwind 4 `@theme` 對應為 `canvas / panel / raised / sunken / line / line-strong / fg / fg-muted / fg-subtle / accent / accent-fg / accent-soft / danger / danger-soft / success / warning`。
- **重點色是近白、字是深色**：主按鈕 `bg-accent text-accent-fg`。彩色只用在狀態：紅＝錯誤、綠＝完成、黃＝過期／警告。
- **字體**：IBM Plex Sans（400/500/600）＋ Noto Sans TC 備援，等寬 IBM Plex Mono（英文 prompt、秒數、金額）。基本字級 14px。取代現在的 Geist。
- **圓角**：控制項 6px（`--radius-control`）、面板 10px（`--radius-panel`）。
- **圖示**：新增 `lucide-react`（IGiveUpOnLife 同一套），只用在有意義的地方（展開、刪除、播放狀態），不當裝飾。
- **共用元件**（放 `components/ui/`，從 IGiveUpOnLife 複製後調整）：`Button`、`Segmented`（取代比例／秒數／解析度／音訊的按鈕組）、`PanelSection`（設定面板的區塊，可收合）、`Dialog`（取代現在的 `Modal`）。

## 整體框架

整頁固定高度（`h-dvh`），不整頁捲動；各欄自己捲動。

**頂列（48px，兩個模式共用）**
`Jola Omni`｜模式切換（單鏡／分鏡，Segmented）｜（分鏡模式才有）專案下拉＋新專案／刪除、步驟 ①②③④｜右側：語言、使用方式、API 設定。

## 單鏡模式

- **左欄 340px（panel）**：主圖與參考圖、描述、比例、音訊、進階設定（解析度、秒數、排除內容、結束畫面）、預估費用、「AI 建議提示詞」與「直接生成」。AI 建議出來後，欄位編輯（`PromptEditor`）接在同一欄下方。
- **主區（canvas）**：結果影片置中、依比例盡量放大；下方是下載、重新生成、延伸、送出的英文提示詞。尚未生成時顯示主圖預覽或空狀態說明。

## 分鏡模式

**① 專案設定**：主區置中一張面板（寬 560px），欄位同現在：名稱、產品圖、包裝文字、比例、調性、「下一步」。沒有鏡頭欄與設定面板。

②③④ 共用三欄：

| 區域 | 寬度 | 內容 |
|---|---|---|
| 鏡頭欄 | 220px | 每鏡一列：縮圖（③ 之後顯示選定圖）、鏡號、畫面描述前幾個字、狀態點；底部總秒數；點一列＝選取該鏡 |
| 主區 | 自適應 | 依步驟顯示（下述），內容以大畫面為主 |
| 設定面板 | 340px | 目前選取這一鏡的設定與動作；最下方固定一顆主按鈕，按鈕上標費用 |

狀態點：灰＝尚未處理、白＝有圖未選、綠＝已選圖／影片完成、黃＝過期、紅＝失敗、轉圈＝生成中。

**② 分鏡表**
- 主區：腳本來源（腳本圖縮圖＋文字）、「整理成分鏡表」、AI 建議、對話。
- 設定面板：選取鏡頭的畫面、運鏡、畫面文字、包裝入鏡、AI 優化。
- 主按鈕：「確認分鏡表，生成分鏡圖（$x）」。

**③ 分鏡圖**
- 主區預設「單鏡」：選取鏡頭的候選圖大圖並排（選中的加白框），點圖放大；可切換「總覽」：全部鏡頭一格一列，每列是該鏡候選圖的小圖，可直接點選。
- 設定面板：改動說明、英文提示詞（可展開）、重生張數 1／2、刪除選取的候選圖、過期與包裝提示；面板底部是全專案的定稿尺寸與「重出」。
- 主按鈕：「下一步」（每鏡都選好才可按）；選取鏡頭的「重生 n 張（$x）」在面板內。

**④ 影片**
- 主區：選取鏡頭的影片（沒有影片時顯示定稿圖），依比例盡量放大，下方是播放狀態、下載、延伸。
- 設定面板：秒數、配樂、解析度、結束畫面、五個欄位（`PromptEditor`，可收合的替代選項）、送出的英文提示詞。
- 主按鈕：「生成這鏡（$x）」／「重生」／「重試」；鏡頭欄頂端放「全部生成（$x）」。

## 不變的部分

- `lib/`、`services/`、`hooks/` 的邏輯與介面不動（只在需要時加 UI 用的小 helper，並附測試）。
- 花費確認、關卡規則、IndexedDB 專案、背景工作行為不變。
- 中英文語系；新增的文字一律進 `locales/`。

## 測試

- 既有單元測試全數通過。
- 新增的純函式（例如鏡頭狀態點的判斷）加 Vitest 測試。
- 用瀏覽器實際走一次單鏡模式與分鏡模式 ①–④（影片用 mock），並截圖比對：頂列、三欄、③ 總覽切換、④ 影片放大、1280px 與 1440px 寬度下不破版、窄螢幕可閱讀。

## 不做

- 淺色主題、手機操作最佳化、時間軸（方案 B）、新功能。
